# What the deployed site needs to run.
#
# torch and torchvision are deliberately absent. On Linux the PyPI torch wheel
# drags the whole NVIDIA CUDA runtime in behind it, which is gigabytes on a
# host that has no GPU to use it. Removing it also removes matplotlib and
# noisereduce, because those two are imported in exactly the same place and
# nowhere else: bird_classifier/classify.py.
#
# The cost is that bird classification stops working. classify.py is imported
# lazily, so the site still boots and every other page is unaffected, but a
# request that actually classifies a call will raise ImportError and return a
# 500. Everything else here is needed the moment Django starts: librosa in
# particular is imported at module level by bird_classifier/forms.py and
# file_handler.py, so it cannot come out without editing those.
#
# To put the classifier back without the CUDA payload, install the CPU-only
# build from PyTorch's own index, which is a fraction of the size:
#
#   pip install --index-url https://download.pytorch.org/whl/cpu \
#       torch==2.4.0 torchvision==0.19.0
#   pip install matplotlib==3.9.2 noisereduce==3.0.2
#
# Transitive dependencies are left to pip rather than pinned, so this installs
# against whatever Python the host offers instead of demanding a wheel that may
# not exist for it. The versions below are the ones the site was built against.

# ── Django and the site ──────────────────────────────────────────────────────

# ── minecraft: the SFTP pull from the game host ──────────────────────────────

# ── loaded when the apps load ────────────────────────────────────────────────
# librosa pulls numba and llvmlite with it; the numpy pin is what keeps that
